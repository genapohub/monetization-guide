# 商业化方法论

## 一、场景识别

| 场景 | 名称 | 判断条件 | 产出量 |
|------|------|---------|--------|
| 场景一 | 0→1 商业化体系搭建 | 新产品、无付费模式、无定价体系 | 10-12类 |
| 场景二 | 中大型商业化项目 | 新付费产品线、新市场拓展、定价重组 | 6-8类 |
| 场景三 | 小优化/定价调整 | 单SKU调价、促销活动、套餐微调 | 2-3类 |
| 场景四 | 商业化模式转型 | 免费→付费、一次性→订阅制、C端→B端 | 8-10类 |
| 场景五 | 商业化探索 | 新变现模式可行性、竞品商业模式分析 | 3-4类 |

## 二、场景一产出清单

1. 市场分析（TAM/SAM/SOM、付费意愿调研、竞品定价对比）
2. 商业模式设计（B2C订阅/B2B SaaS/广告/交易抽佣/增值服务组合）
3. 定价策略（价值定价/竞争定价/成本加成/分层定价）
4. SKU/Package设计（Free/Pro/Enterprise权益矩阵）
5. 支付体系方案（支付渠道/账期/发票/退款/SLA）
6. 销售漏斗设计（Leads→MQL→SQL→Opportunity→Closed Won）
7. 客户分层与定价（SMB/Mid-Market/Enterprise差异化方案）
8. CRM体系方案（客户管理/合同管理/续费预警）
9. 商业化指标看板（MRR/ARR/LTV/CAC/回款周期/Churn Rate）
10. 商业化运营SOP（开通/续费/升级/降级/退订/流失挽回）
11. 销售团队架构（直销/渠道/电销/在线自服务）
12. 法务合规（服务协议/隐私政策/SLA条款/退款政策/数据合规）

## 七、商业化通用规范

### 定价规范
- 套餐数量≤4个（含Free），避免选择过载
- Free版必须有价值但「不够好」：要么功能受限，要么用量受限
- 旗舰版应有10x价格和3x价值
- 所有价格以年付为默认展示，月付作为选项
- B2B定价需包含实施费/培训费（不与订阅费混合）

### 销售漏斗规范
- 每阶段转化率须有行业基准对照
- 销售周期分级：SMB≤30天、Mid-Market≤90天、Enterprise≤180天
- CRM记录必须包含：来源渠道、决策人、预算周期、竞争对手、下一步行动

### 客户成功规范
- NPS/CSAT季度追踪
- 健康度评分模型：产品使用深度+使用频率+关键功能渗透率+客户反馈
- 流失预警：连续2周关键指标下降触发客户成功介入
- 续费提醒：到期前90天启动续费流程

### 数据追踪规范
- MRR/ARR每日追踪，含New/Expansion/Contraction/Churned明细
- LTV/CAC按渠道/客群/套餐拆分
- 回款周期（DSO）月度追踪
- Churn Rate区分Logo Churn和Revenue Churn

## 八、产出质量检查清单

- [ ] 商业模式清晰可一句话描述
- [ ] 定价有数据/竞品/成本三重支撑
- [ ] SKU权益矩阵边界清晰，无重叠歧义
- [ ] 销售漏斗各阶段定义明确，有转化率基准
- [ ] 客户分层标准可自动识别
- [ ] 商业化指标看板覆盖核心收入指标
- [ ] 法务条款覆盖服务/隐私/退款/数据四方面
- [ ] 财务预测合理且有敏感性分析
- [ ] 有竞品定价对比
- [ ] 客户成功介入流程有明确触发条件
